# Analisis SWOT Diri — Yoga Dwi Pratama

Halaman web analisis SWOT diri sebagai tugas mata kuliah Kecakapan Antar Personal.
Berisi pemetaan kekuatan, kelemahan, peluang, dan ancaman dalam format matriks 2×2 yang interaktif.

## Jalankan Lokal

**Prasyarat:** Node.js

1. Install dependensi:
   `npm install`
2. Jalankan aplikasi:
   `npm run dev`
3. Build untuk produksi:
   `npm run build`

## Deploy ke Vercel

1. Push repositori ini ke GitHub.
2. Di Vercel, pilih **Add New → Project** lalu import repositori tersebut.
3. Framework akan terdeteksi otomatis sebagai **Vite** — tidak perlu konfigurasi tambahan.
4. Klik **Deploy**.
